Analyze a .pcap or .pcapng from tcpdump, Wireshark, a SPAN port or an authorized Wi-Fi monitor. The file is read in this browser tab and never uploaded. Only packet headers are interpreted: addresses, ports, protocols, byte counts and timestamps.

How to make a capture 
sudo tcpdump -i en0 -s 96 -w kavach-capture.pcap
# stop with Ctrl-C, then drop the file above

On Linux, -i any captures across interfaces. Keeping -s 96 retains headers without full payloads. For Wi-Fi monitor-mode captures, use an authorized adapter and channel, and note that encrypted 802.11 payloads cannot be classified. Capture only networks you own or have written permission to monitor.

Windows capture with pktmon 
# PowerShell as Administrator
pktmon start --capture --pkt-size 96 --file-name C:\temp\kavach.etl
pktmon stop
pktmon etl2pcap C:\temp\kavach.etl --out C:\temp\kavach.pcapng

pktmon is built into Windows 10/11 and Windows Server 2019+. Drop kavach.pcapng into the dashboard above. To focus on a critical host, add a filter before capture: pktmon filter add -i 10.20.4.15. Wireshark with Npcap also works: dumpcap -D lists interfaces, then dumpcap -i 1 -s 96 -w C:\temp\kavach.pcapng.

pktmon captures the Windows machine's own stack. Capturing other machines requires a SPAN port, TAP or an authorized endpoint agent.

Capture agent · live metadata

Run it on a network you are authorized to monitor.

The public dashboard is a demonstration. The local agent uses tcpdump to read packet headers on one interface, aggregates them into flows, and serves this same dashboard at 127.0.0.1:8787. It does not capture payloads, credentials or application data. 

git clone https://github.com/BusDec/kavach.git
cd kavach
sudo python3 agent/kavach_network_agent.py --interface en0

On macOS, confirm the Wi-Fi interface with networksetup -listallhardwareports (often en0 or en1). This captures the traffic visible to that host. Capturing other devices requires a TAP, SPAN or authorized monitor-mode deployment — not a browser page. Get written authorization and follow your privacy obligations before capturing any network.

The agent is read-only: it never modifies, injects or blocks traffic. The dashboard classifies applications from ports and flow metadata, not by opening payloads. Imported captures are parsed locally in this tab and are not sent to any server. The optional Sensor hub adds Zeek, osquery and Wazuh adapters, an entity graph and evidence-cited triage at 127.0.0.1:8789.
