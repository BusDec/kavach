Capture agent

Run it on a network you are authorized to monitor.

The public dashboard is a demonstration. The local agent uses tcpdump to read packet headers on one interface, aggregates them into flows, and serves this same dashboard at 127.0.0.1:8787. It does not capture payloads, credentials or application data. 

sudo python3 agent/kavach_network_agent.py --interface en0

On macOS, en0 is usually Wi-Fi. This captures the traffic visible to that host. Capturing other devices requires a TAP, SPAN or authorized monitor-mode deployment — not a browser page. Get written authorization and follow your privacy obligations before capturing any network.
