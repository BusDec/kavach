Expected JSON shape
schema, generated_at, organization, assets[], devices[], resources[], logins[], gaps[]

Each asset needs id, name and controls. devices, resources, logins and gaps are optional. Controls use true, false or null for unverified. See the synthetic register for a complete example.

Collect this machine's posture

The read-only collector checks OS posture, patch state, disk encryption, firewall, local admin membership and listening services. It does not scan the network, install software or change settings. 

python3 agent/kavach_protection_agent.py \
  --asset-name "WS-PRIYA" \
  --criticality high \
  --output protection.json

Then choose protection.json above. The collector is also documented in the agent guide.
