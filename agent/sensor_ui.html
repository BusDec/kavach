matching is local

Add or change the hub watchlist with --critical-assets when starting the service. The browser dashboards use a separate local watchlist.

Critical asset accessAny sensor event touching the configured watchlist.
Identity and network correlationExternal success plus related flow or process activity within 30 minutes.
Suspicious process egressPowerShell, cmd, curl, wget or similar processes contacting external hosts.
Authentication burst and sprayFive failures for one account, or one source against three or more accounts, in ten minutes.
Lateral movementThree or more internal SMB, RDP or SSH destinations from one host in ten minutes.
